# Categorical Encoding Techniques in Python

A clean Jupyter Notebook demonstrating essential data preprocessing techniques using **Pandas** and **Scikit-Learn**.

## 🔍 What's Covered?
- **One-Hot Encoding**: Converting nominal categorical features (like colors) into binary columns without introducing ordinal bias.
- **Target (Mean) Encoding**: Encoding high-cardinality categorical features (like city names) using the mean of the target variable (`price`).

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Scikit-Learn
